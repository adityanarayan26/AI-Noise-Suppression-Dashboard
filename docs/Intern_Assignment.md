# Intern Assignment

## Project Title

AI Noise Suppression Dashboard

---

## Background

You have been provided with a working frontend dashboard and backend API structure.

Your task is to build and integrate AI/ML capabilities into the system.

The final solution should improve audio quality during online interviews and provide meaningful audio analytics.

---

## Project Goal

Develop an AI-powered system that can:

1. Remove background noise
2. Detect different noise types
3. Measure voice clarity
4. Generate audio quality scores
5. Integrate results into the dashboard

---

## Core Requirements

### 1. Background Noise Suppression

Reduce unwanted background sounds from interview audio.

Examples:

* Fan Noise
* Traffic Noise
* Air Conditioner Noise
* Background Conversation
* Environmental Noise

---

### 2. Noise Classification

Identify the type of detected noise.

Expected Categories:

* Fan Noise
* Traffic Noise
* Keyboard Typing
* Background Conversation
* AC Noise
* Other

---

### 3. Voice Clarity Scoring

Generate a score between:

```text
0 - 100
```

Higher scores should indicate better voice quality.

---

### 4. Audio Quality Analysis

Create meaningful metrics such as:

* Voice Clarity
* Noise Level
* Speech Presence
* Audio Quality Score

---

### 5. Dashboard Integration

Connect AI-generated outputs to the existing dashboard.

The dashboard should display:

* Noise Levels
* Noise Categories
* Voice Clarity
* Audio Quality Metrics

---

## Suggested Workflow

1. Research suitable AI/ML approaches.
2. Select datasets.
3. Train or integrate models.
4. Evaluate performance.
5. Integrate with backend APIs.
6. Display results on dashboard.
